# Agent skills and engineering toolkit

This repository already has project-specific `AGENTS.md` and Spec Kit guidance. This folder indexes the requested upstream skill sources without duplicating or overwriting those rules.

## Available locally
- `/AGENTS.md` — project workflow and constraints.
- `/antislop.md` — Anti-Slop core rules and delivery gate, copied from https://github.com/miqdadbadjuber/anti-slop (MIT).

## Additional skills

Install into the Codex project from the repository root, after reviewing existing `.agents/skills/` content:

```bash
npx skills@latest add mattpocock/skills -a codex
npx skills@latest add miqdadbadjuber/anti-slop --all -a codex
```

Select the relevant Matt Pocock engineering skills (TDD, diagnosing-bugs, codebase-design, code-review); avoid duplicate copies across agent-specific directories.

## UI/UX Pro Max

This project has a user-facing Streamlit interface. Install the full generated skill and its design-search data with:

```bash
npx ui-ux-pro-max-cli init --ai codex
```

Use the existing product constraints and UI patterns as the source of truth. The full skill is generated by the CLI; a partial hand-copied prompt is not equivalent.

## Spec Kit

Spec Kit is already represented by this repository's `.specify/` constitution and feature specs. Keep those artifacts; do not reinitialize or overwrite them. For future projects or if the CLI is missing:

```bash
uv tool install specify-cli
specify version
```

For this existing project, follow the official adoption guidance before adding CLI-generated assets: https://github.com/github/spec-kit/blob/main/docs/how-to/adopting-spec-kit.md
