STAC Browser CORS Feasibility Probe

Run this page from an HTTP(S) origin, ideally the eventual GitHub Pages origin. It tests browser access, not merely whether a URL responds from a server.

Important: A failed browser fetch may be CORS, network, DNS, or TLS. The browser intentionally hides some details. A successful JSON fetch proves only that endpoint and operation work from this origin. Image display is tested separately because <img> can load cross-origin images without granting JavaScript access to their bytes.
